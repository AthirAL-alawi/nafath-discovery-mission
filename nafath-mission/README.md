# Nafath Discovery Mission

Welcome. This repository contains the instructions for the first selection stage
of the Nafath Training Program.

## Where to start

1. Read [START_HERE.md](START_HERE.md).
2. Read [PROGRAMME.md](PROGRAMME.md).
3. Open **your version folder** (the version code is in your invitation email):
   - [versions/V1/MISSION.md](versions/V1/MISSION.md)
   - [versions/V2/MISSION.md](versions/V2/MISSION.md)
   - [versions/V3/MISSION.md](versions/V3/MISSION.md)
   - [versions/V4/MISSION.md](versions/V4/MISSION.md)
4. Use [GITHUB_HELP.md](GITHUB_HELP.md) to complete the GitHub steps.
5. Check [FAQ.md](FAQ.md) if anything is unclear.

Complete only the version given in your email. Work completed for a different
version will not be accepted.

This repository is read-only. Do not open issues or pull requests here.
Your work goes in **your own** repository.
